# Projeto 1 — Cena 2D com Textura e Animação

Projeto desenvolvido para a disciplina de **Computação Gráfica** da **PUC-Rio**.

## Descrição

O projeto consiste no desenvolvimento de uma **animação de um mini-sistema solar em 2D**, utilizando técnicas de computação gráfica, texturas e animação.

A cena representa um sistema composto pelos seguintes corpos celestes:

* Sol
* Terra
* Lua
* Mercúrio ou Vênus

O objetivo é desenvolver uma cena 2D animada que represente a movimentação dos corpos celestes, utilizando os conceitos apresentados na disciplina.
